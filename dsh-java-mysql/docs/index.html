DSH MySQL Studio · 操作演示

独立验证与 DSH-JAVA 内插件调用的完整操作流程与效果截图
Admin UI 默认端口 8091
本演示分为两部分：
① 独立验证——启动 dsh-java-mysql-app，配置数据源后直接使用管理后台；
② DSH-JAVA 插件调用——在 DSH-JAVA 中加载插件，由 Agent 直接调用插件工具查询数据库。
第一部分

启动插件配置数据源进行独立验证

启动管理后台并配置数据源，独立验证对话查询、连接配置、SQL 监控、界面与性能分析。
1

新对话 · 列出所有表和行数

通过 AI 对话助手，自然语言查询数据库，自动列出所有表及行数统计。
启动管理后台后新建对话，向 AI 提问「列出所有表和行数」，Agent 自动返回库表清单。
2

配置数据库源链接

填写主机、端口、数据库、用户名与密码，保存并测试数据库连接。
点击右上角「＋ 连接」，录入数据库实例的连接信息，保存并测试连通性。
3

查看 SQL 监控

查看 SQL 控制台执行结果、连接数、慢查询与进程等实例快照。
切换到「监控」页签，查看连接数、慢查询、锁等待、进程列表等实时性能快照。
4

调整界面色系

切换界面主题，调整整体配色与显示风格。
点击右上角主题切换按钮，在明暗色系之间切换，调整界面显示风格。
5

新对话 · 分析数据库性能状态

通过 AI 对话分析数据库性能状态，诊断慢查询、连接数与锁等待等问题。
再开新对话，让 AI 分析实例性能状态，找出慢查询隐患并给出优化建议。
第二部分

DSH-JAVA 内加载插件，直接进行插件调用

在 DSH-JAVA 管理后台安装并激活插件，由 Agent 直接调用插件工具完成数据库查询。
6

DSH-JAVA 内增加 dsh-java-mysql 插件

在 DSH-JAVA 管理后台中安装并激活 dsh-java-mysql 插件。
进入 DSH-JAVA 的插件管理页，上传插件 jar 并激活 dsh-java-mysql 插件。
7

DSH-JAVA 内开启新会话

在 DSH-JAVA 中开启新会话，准备使用已加载的插件能力。
在 DSH-JAVA 中新建会话，Agent 已具备插件工具能力，等待用户提问。
8

直接通过插件进行查询

无需独立管理后台，直接通过 Agent 调用插件工具查询数据库。
在会话中直接提问，Agent 识别意图后自动调用 plugin__dsh-java-mysql-plugin 工具查询数据库。
9

展示基于插件的查询结果

展示插件查询返回的真实数据结果，验证插件调用链路正确。
Agent 返回插件查询到的真实数据，完成从「插件调用」到「结果展示」的完整闭环。
